# Bookmarked
Bookmarked is THE website for any book lover to find their next read and explore the worlds within their books.
# Features
- Book Browsing: Search for books by title, author, or keywords (via Open Library API) and view NYT bestseller lists.
- Search & Filtering: Ability to browse books by category, genre, or list type (NYT lists).
- Organization & Personalization: Save books to “Want to Read,” “Currently Reading,” or “Finished” lists.
- Aesthetic Collections: Visually curated boards for books, inspired by Pinterest-style picture pins and Tumblr moodboards, allowing users to arrange covers, quotes, and images into thematic or mood-based collections.
